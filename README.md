# cryptogram — 替换密码解谜

终端里的古典密码游戏：随机挑一句名言，用单表替换密码加密，你通过猜字母映射逐字破解。

## 玩法

```
$ python -m cryptogram
密文：
Wnk lag ft zkt e ztjgjqz, qzzh bj qnk cjnjlwmd.
命令：猜 A=T（把密文 A 猜成明文 T）/ freq（字母频率）/ 撤回 A / 放弃 / 退出

当前进度：
___ ___ __ ___ _ ________, ____ __ ___ ________.

你的猜测> 猜 W=T
...
```

- 每句名言只显示作者，内容被加密后需要你自己破译。
- `freq` 显示密文字母频率——英语里 E、T、A、O、I、N 最常见，是很好的切入点。
- 猜错了不扣分，可以 `撤回 A` 撤销某个字母的猜测；两个密文字母猜成同一个明文时会提醒冲突。
- 全部字母猜对即获胜；`放弃` 直接揭晓答案和密钥。

## 用法

```
python -m cryptogram            # 开始一局（交互）
python -m cryptogram --seed 7   # 可复现的同一谜题
python -m cryptogram --quote 3  # 指定第几条名言（0 起）
python -m cryptogram --reveal   # 直接显示谜题和答案（非交互）
```

## 实现说明

- 纯标准库（argparse / sys / random），Python 3.10+。
- 内置 31 条名言：选用莎士比亚、老子、苏格拉底等公有领域/流传广泛的短句，避开现代版权文本。
- 密钥是 A–Z 的随机置换（`make_key`），加密保持大小写与标点；`solved` 用逆映射校验全对。

## 真实验证

- `python3 -m py_compile cryptogram.py __main__.py` 通过。
- 100 个种子：密钥都是合法置换（26 个不同密文字母，一一对应）。
- 全部 31 条名言：加密→用逆密钥解码，逐字还原原文。
- 管道/pty 模拟交互：`freq` 输出频率、`猜 A=Q` 生效、非法格式被拒、`撤回 A` 生效、
  `放弃` 揭晓答案与原文；用正确密钥逐字母猜中后判胜并显示原文。
- `--reveal --quote 0 --seed 1` 输出密文、原文、密钥三件套一致。
- 修过的 bug：帮助文案写「猜 A=T」，但解析没去掉「猜」前缀，导致所有带前缀的猜测
  都被判格式非法——pty 交互测试抓到，已修复（去掉可选的「猜」前缀再解析）。

## 已知局限

- 名言只有 31 条，玩多了会重复——这是小巧取舍，不是 bug。
- 没有难度分级和计分；单表替换本身偏简单，有频率分析基础几分钟可破。
- 交互模式需要 tty；非终端请用 `--reveal`。
